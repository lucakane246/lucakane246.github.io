One-time setup

  1. Open GitHub → new fine-grained token.
  2. Name it Site log. Set expiration to No expiration (or a year).
  3. Repository access: Only select repositories → lucakane246.github.io.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate, copy the token, paste it here. It's saved only in this browser.

Each line becomes a bullet. Sending replaces the previous day's update. Start a line with a project name and a colon to link it to that project. Ctrl/⌘ + Enter also sends.
